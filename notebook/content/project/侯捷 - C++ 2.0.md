- `decltype` 是 C++11 引入的关键字，用于**在编译时查询表达式或实体的确切类型**
- 通过 `decltype(nullptr)` 定义 `std::nullptr_t`，C++ 实现了类型安全的空指针表示，彻底解决了传统 `NULL` 和 `0` 导致的类型歧义问题。

具体规则

| 表达式类型    | `decltype` 推导结果                   | 示例                       |
| -------- | --------------------------------- | ------------------------ |
| 变量名      | 变量的声明类型                           | `int x;` → `int`         |
| 左值表达式    | T&（左值引用）                          | `(x)` → `int&`           |
| 纯右值表达式   | T（非引用类型）                          | `x+1` → `int`            |
| 将亡值表达式   | T&&（右值引用）                         | `std::move(x)` → `int&&` |
| 函数调用     | 函数返回类型                            | `func()` → 返回类型          |


#### void*
 -  `void*`不关联任何具体的数据类型。它只是存储一个内存地址（就像其他指针一样）
 - 不能直接解引用
 - 不知道类型, 也不知道大小, 当然也不能指针运算
 - 显式转换为其他类型后才能使用 

```cpp
void* vp = &num;
int* int_ptr = (int*)vp;  // 转换为int指针
printf("%d", *int_ptr);   // 正确：输出10
```

```cpp
int* arr = (int*)malloc(10 * sizeof(int)); // malloc返回void*
```

## Uniform Initialization
核心概念：
1. 语法：使用花括号{}初始化对象
2. 目的：解决C++中多种初始化方式（如小括号、等号、花括号）带来的混淆，并提供一致性

适用场景：
1. 初始化变量（包括基本类型、数组、结构体、类等）
2. 初始化容器（如std::vector, std::map等）  
3. 初始化容器（如 std::vector, std::map 等）
4. 初始化动态分配的数组
5. 初始化类的成员（在构造函数初始化列表中）
6. 函数返回值的初始化
7. 初始化聚合类型（aggregate types）

![[attachments/Pasted image 20250703200509.png]]


#### 用法
```cpp
// 1. 基本数据类型初始化
int x{42};          // 整型
double d{3.14};     // 浮点型
char c{'A'};        // 字符型
bool flag{true};    // 布尔型

// 2. 数组和聚合类型初始化

// 数组
int arr[]{1, 2, 3, 4}; 

// 结构体（聚合类型）
struct Point { int x; int y; };
Point p{10, 20};  // 直接初始化成员

// 3. STL 容器初始化

std::vector<int> nums{1, 2, 3, 4};
std::map<std::string, int> ages{
    {"Alice", 30},
    {"Bob", 25}
};

// 4. 动态内存分配

int* ptr = new int{42};         // 单个对象
int* arr = new int[4]{1,2,3,4}; // 数组

// 5. 类成员初始化（构造函数初始化列表）

class Widget {
public:
    Widget() : width{100}, height{50}, data{new char[1024]{}} {}
private:
    int width;
    int height;
    char* data;
};

// 6. 函数返回值

std::vector<int> createVector() {
    return {1, 2, 3}; // 直接返回初始化列表
}

// 7. 避免"最令人烦恼的解析"(Most Vexing Parse)

// 传统方式的问题
Time t(12, 30);   // 正确：调用构造函数
Time t();         // 问题：函数声明而非对象创建！

// 统一初始化解决
Time t1{12, 30};  // 正确：调用构造函数
Time t2{};        // 正确：调用默认构造函数
```

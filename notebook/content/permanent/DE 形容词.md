## 一、形容词词尾变格

1、接*定冠词*的形容词词尾

|   |   |   |   |   |
|---|---|---|---|---|
|定|m|n|f|pl|
|N|-e|-e|-e|-en|
|G|-en|-en|-en|-en|
|D|-en|-en|-en|-en|
|A|-en|-e|-e|-en|

只有5个-e,其他都是-en

这种变化模式叫弱变化，同时使用于以下强变化词（定冠词也是强变化）：

|   |   |   |   |
|---|---|---|---|
|dieser|jener|mancher|solcher|
|welcher|jeder|alle|viele|
|wenige|mehrere|einige|keine|

2、接*不定冠词*ein的形容词词尾

|   |   |   |   |   |
|---|---|---|---|---|
|不定|m|n|f|pl|
|N|-er|-es|-e|-e|
|G|-en|-en|-en|-en|
|D|-en|-en|-en|-en|
|A|-en|-es|-e|-e|

这种变化模式叫混合变化，第二、三格与弱变化相同，第一、四格与强变化相同

3、*零冠词*的形容词词尾

当形容词修饰的名词前面没有冠词，就是零冠词的情况

|   |   |   |   |   |
|---|---|---|---|---|
|零|m|n|f|pl|
|N|-er|-es|-e|-e|
|G|-es|-es|-er|-er|
|D|-em|-em|-er|-en|
|A|-en|-es|-e|-e|

这种变化模式叫**强变化**，和定冠词的变格是一样的

4、以 -a 结尾的形容词无词尾变化 如 prima extra

## 二、比较级和最高级

1、词尾变化

- 比较级：加er (+形容词词尾(作定语))  加-er  (+als) （作表语）
- 最高级：加-st (+形容词词尾(作定语))  am …sten （作表语）
![[attachments/Pasted image 20250103154148.png]]c. 变元音
不规则的：

|      |        |         |             |
| ---- | ------ | ------- | ----------- |
| groß | größer | größte  | am größten  |
| hoch | höher  | höchste | am höchsten |
| nah  | näher  | nächste | am nächsten |
d. -d -t -s -ss -z -sch等特殊，要加多个e

2、比较的其他表达

so … wie

ebenso … wie

genauso … wie

nicht so … wie

## 一、时态

#### 1、现在时

- 一般变化i

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
|ich|du|er/sie/es|wir|ihr|sie|Sie|
|-e|-st|-t|-en|-t|-en|-en|

- 再加e：以 -t -d -m -n 结尾的动词，词尾前面还要再加e 如arbeitet

- 不加s：以 -s -ss -ß -x -z 结尾的du不加s

- el er : ich sammle ich verbessre

- 元音变化一般是第二第三人称，大多数是这几种：
    - e -> i                   sprechen spricht
    - e -> ie                  lesen liest
    - a, o, u -> ä, ö, ü       fahren fährt

#### 2、现在完成时

- 一般变化：haben + ge+词干+t
    - ge+词干+t 也叫第二分词

- 再加e：以 -t -d -m -n 结尾的动词，词尾前面还要再加e

- 可分动词 ge 加在前缀和词干之间；
    - 含有不可分前缀动词不加ge， ver- be- zer- über- wieder-
    - -ieren结尾的动词 passieren passiert

sein： 表示方向、位置或状改变的时候；以及状态被动式(Zustandpassiv)
haben： 其他

- nachdem从句必须要用完成时
    - Nach dem Abendessen mache ich Hausaufgaben.
    - Nachdem ich zum Abend gegesen habe, mache ich Hausaufgaben.

#### 3、过去时

一般变化： 词干 + -te + 人称词尾

beginnen begann begonnen
finden fand gefunden
现在时i  过去时a 完成时o或者u

sprechen spricht sprach gesprochen
现在时e 三单i  过去a 完成o

#### 4、过去完成时

就是过去时+现在完成时
hatten gemacht

#### 5、将来时

- 第一将来时：表示将来发生的事
    - 形式：werden + 动词不定式(Infinitiv)
    - 动词不定式放在句末

- 第二将来时：表示在将来的某个时间点前已完成的事
    - 形式：werden + 动词第二分词 + haben

## 二、反身动词

- sich + 动词

反身代词sich的人称变化

|   |   |   |   |   |   |
|---|---|---|---|---|---|
|ich|du|er/sie/es|wir|ihr|sie/Sie|
|mich|dich|sich|uns|euch|sich|
|mir|dir|||||

- 真反身动词：必须与反身代词sich连用，如 sich erholen, sich erkundigen
- 假反身动词：可以不带sich 人三物四

- 反身动词的主语是复数人称的时候表示互相关系
    - 这种关系也能用（介词+）einander表示

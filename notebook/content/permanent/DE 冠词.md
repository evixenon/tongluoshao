## 一、定冠词

|   |   |   |   |   |
|---|---|---|---|---|
||m|n|f|plu.|
|N|der|das|die|die|
|G|des|des|der|der|
|D|dem|dem|der|den|
|A|den|das|die|die|

归纳一下：

|   |   |   |   |   |
|---|---|---|---|---|
||m|n|f|plu.|
|N|-r|-s|-e|-e|
|G|-s|-s|-r|-r|
|D|-m|-m|-r|-n|
|A|-n|-s|-e|-e|

这套规则又叫强变化，同时适用于以下词：

|   |   |   |   |
|---|---|---|---|
|dieser|jener|mancher|solcher|
|welcher|jeder|alle|viele|
|wenige|mehrere|einige|keine|

## 二、不定冠词

|   |   |   |   |
|---|---|---|---|
||m|n|f|
|N|ein|ein|eine|
|G|eines|eines|einer|
|D|einem|einem|einer|
|A|einen|ein|eine|

这个是混合变化

弱变化第一格第四格同不定冠词，第二格第三格全是en

## 三、物主冠词

物主冠词相当于物主代词作冠词用

单数变化同不定冠词，复数变化同定冠词

|   |   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|---|
|ich|du|er, es, man|sie|wir|ihr|sie|Sie|
|mein|dein|sein|ihr|unser|euer|ihr|Ihr|

只有euer在后加变化时会变成eure-, 如 eurem, eures

## 四、零冠词

零冠词就是没有冠词啦

# 3D-3D 对齐技术方案

## 1. 问题与方案

### 1.1 待解决的问题
- 大模型 3D 输出坐标点的方向, 视角关系, 尺度与世界坐标系不一致。
- 因此需要将大模型输出映射到现有世界坐标系下，供后续流程使用。

### 1.2 当前输入条件
- 双目 2D 关键点（左右视角）。
- 双目 2D 三角化得到的 3D 点（原方案，可信度不足，但可作为参考）。
- 相机标定信息（投影矩阵/内外参）可用。
- 大模型输出每个视角独立的一套 3D（归一化、无置信度、关节对应关系已处理）。

### 1.3 解决方案
- 目标: 估计一个**转换模型**, 将大模型输出的坐标映射到世界坐标
- 主流程：`RANSAC` 去外点 + `Umeyama` 闭式求解 Sim(3) + `Huber(IRLS)` 精修
- 左右视角分开估计两套变换模型

### 1.4 方案解释
- **Umeyama 算法**用于求解两组已配对点集间的最优**相似变换（Sim(3)）**参数，即旋转 `R`、平移 `t`、缩放 `s`，使变换后点集与目标点集的均方误差最小。
- **RANSAC 思路**：
1. 假设数据由 **内点（Inliers，符合模型）** + **外点（Outliers，噪声 / 错误）** 组成。
2. 随机抽最少样本** → 拟合模型 → 统计内点数量。
3. 重复迭代，保留内点最多或误差最小的模型为最优解。
- **Huber Loss** 是鲁棒损失，用于“软抑制”中等/大残差，不像 RANSAC 那样硬切内外点。



## 2. 数学模型

### 2.1 对齐模型
给定源点（LLM 3D）`x_i` 与目标点（参考 3D）`y_i`：

$$
y_i \approx s R x_i + t
$$

其中：
- `s > 0`：全局尺度
- `R \in SO(3)`：旋转矩阵
- `t \in \mathbb{R}^3`：平移向量

### 2.2 最小二乘目标
$$
\min_{s,R,t}\sum_i \|y_i-(sRx_i+t)\|^2
$$
### 2.3 残差与指标
- 点误差：`e_i = || y_i - (s R x_i + t) ||`
- 常用评估：
  - 内点率（Inlier Ratio）
  - 内点 RMSE

## 3. 核心算法设计

### 3.1 Umeyama（闭式 Sim(3)）
用于在给定点对下快速求 `s,R,t`，主要步骤：
1. 计算源/目标点加权质心；
2. 去中心化；
3. 构建协方差矩阵；
4. SVD 分解；
5. 处理反射（`det < 0`）；
6. 求 `R`、`s`、`t`。

特点：
- 闭式解，快、稳定、无复杂迭代。
- 对离群点敏感，因此必须配合鲁棒机制。

### 3.2 RANSAC（外点剔除）
主循环逻辑：
1. 随机采样最小点集（建议 4~6 对）；
2. 用 Umeyama 拟合候选模型；
3. 在全量点上计算残差；
4. 按阈值判定内点；
5. 选择“内点最多/误差最小”的模型；
6. 用最佳内点集重新拟合。

作用：
- 在遮挡、误匹配、坏点存在时，先找到可信点子集。

### 3.3 Huber + IRLS（内点精修）
在 RANSAC 给出的内点集合上做鲁棒精修：
- 使用 Huber 损失减少大残差点影响；
- 用 IRLS 迭代更新权重；
- 每轮执行“加权 Umeyama”更新模型；
- 收敛后得到最终 `s,R,t`。

作用：
- 比纯硬阈值 RANSAC 更平滑，精度更高。


## 4. 调参与排障手册

### 4.1 核心参数建议

| 参数 | 含义 | 建议初值 | 调大影响 | 调小影响 |
|---|---|---:|---|---|
| `inlier_thresh` | 内点阈值（mm） | 60~100 | 内点增多，误匹配风险增 | 内点更纯，易内点不足 |
| `ransac_max_iters` | RANSAC迭代次数 | 1000~2000 | 更稳但更慢 | 更快但失败率增 |
| `ransac_min_sample` | 每次最小采样点数 | 4~6 | 更稳但更难采到有效样本 | 更易采样但模型不稳 |
| `min_inliers_to_accept` | 接受模型的最小内点数 | 12~30 | 结果更稳，失败率可能升 | 更易通过，质量可能差 |
| `huber_delta` | Huber阈值（mm） | 40~60 | 更接近 L2，受外点影响增 | 更鲁棒，但可能欠拟合 |
| `segment_length` | 分段长度（帧） | 30~120 | 更平滑，可能滞后 | 更灵敏，可能抖动 |

### 4.2 常见现象与处理
1. **内点率过低**
- 检查时间同步与关节映射是否错位；
- 适当增大 `inlier_thresh`；
- 提高 `ransac_max_iters`。

2. **结果抖动明显**
- 延长 `segment_length`；
- 增加相邻段参数平滑；
- 提高 `min_inliers_to_accept`。

3. **尺度偶发跳变**
- 对 `s` 增加变化率约束；
- 内点不足时回退上一段模型；
- 排查是否某些关节系统性错误。

4. **RANSAC 经常失败**
- 降低最小采样点数（如 `6 -> 4`）；
- 放宽阈值；
- 增加可用点对数量。


## 5. 验证与验收

### 5.1 离线指标
- 内点率；
- 对齐后内点 RMSE；
- 骨长稳定性（帧间方差）；
- 时序平滑度（速度/加速度突变率）。

### 5.2 可视化检查
- 对齐前后轨迹对比（关键关节）；
- 分段尺度 `s` 曲线；
- 失败段落标记与回放。

### 5.3 建议验收门槛（可按业务调整）
- 内点率 `>= 60%`（示例值）；
- 内点 RMSE `<= 80 mm`（示例值）；
- 连续失败窗口占比 `<= 5%`（示例值）。



## 6. 术语表
- **Sim(3)**：相似变换群，包含旋转、平移、统一缩放（`s, R, t`）。
- **Umeyama**：通过 SVD 闭式求解两组点云相似变换的经典算法。
- **RANSAC**：随机采样一致性算法，用于在外点存在时估计稳健模型。
- **Huber Loss**：分段鲁棒损失，小残差按 L2，大残差近似 L1。
- **IRLS**：迭代重加权最小二乘，用于求解带鲁棒损失的优化问题。
- **Inlier/Outlier**：符合模型的样本/不符合模型的样本。

## 7. 总结
- 在做什么：将大模型相对 3D 对齐到工程世界坐标系。
- 为什么这么做：三角化在遮挡场景不稳定；大模型形状信息可用，但尺度与坐标系不一致。
- 技术路线：`RANSAC` 去外点 + `Umeyama` 闭式求 Sim(3) + `Huber` 精修。
- 风险：参考 3D 偏差继承、遮挡导致可观测性不足。
- 调优抓手：内点阈值、最小内点、分段长度、Huber 阈值与回退策略。

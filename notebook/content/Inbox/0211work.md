#### 解决方案：基于时空约束的多目标优化
---

##### 1. **肢体长度约束（空间约束）**
**实现方法：**
- 解析`02_human_pose.json`中的骨架连接关系（如左肩-左肘-左腕形成的肢体链）
- 计算每对连接关键点的理论长度（取所有帧中该肢体长度的众数或中位数作为基准）
- 构建损失函数：`L_length = Σ(||p_i - p_j||² - l²)`，其中`p_i/p_j`为关键点坐标，`l`为基准长度
- 使用非线性优化（如Levenberg-Marquardt算法）调整关键点位置，最小化长度误差

##### 2. **运动平滑约束（时间约束）**
**实现方法：**
- 对每个关键点构建时间序列轨迹（x(t), y(t), z(t)）
- 使用卡尔曼滤波或双指数平滑（Holt-Winters）去除高频噪声
- 构建加速度约束：`L_smooth = Σ||p_t - 2p_{t-1} + p_{t-2}||²`，抑制不合理的突变
- 对缺失帧使用线性插值或基于LSTM的运动预测补全数据

##### 3. **关节角度约束**
**实现方法：**
- 根据人体运动学限制关节角度范围（如肘关节屈曲0-160度）
- 通过向量计算关节角度：`θ = arccos( (a·b)/(||a||·||b||) )`
- 构建损失函数：`L_angle = ΣReLU(|θ - θ_normal| - θ_threshold)`，约束异常角度

##### 4. **多目标优化框架**
**综合优化函数：**
```python
Total_Loss = w1*L_length + w2*L_smooth + w3*L_angle 
           + w4*L_missing (缺失点约束)
```
- 权重建议：w1=1.0（长度）, w2=0.5（平滑）, w3=0.3（角度）, w4=0.2（缺失）
- 使用基于梯度的优化方法迭代更新坐标，直至收敛

#### 关键代码逻辑（伪代码）
```python
# 读取数据
frames = parse_3Dkeypoints("01_3Dkeypoint.txt") 

# 初始化优化器
optimizer = MultiObjectiveOptimizer(
    length_weight=1.0,
    smooth_weight=0.5,
    angle_weight=0.3
)

# 逐帧优化
for frame_seq in sliding_window(frames, window_size=5):
    # 计算约束
    length_loss = calc_length_loss(frame_seq, skeleton)  # 肢体长度约束
    smooth_loss = calc_smooth_loss(frame_seq)           # 运动平滑约束
    angle_loss = calc_angle_loss(frame_seq)             # 关节角度约束
    
    # 综合优化
    optimized_frame = optimizer.step(
        frame_seq,
        length_loss + smooth_loss + angle_loss
    )
    
    # 更新数据
    update_frames(optimized_frame)

# 处理缺失点
fill_missing_points(frames, method="cubic_spline") 
```

#### 最常用的 shell 命令（Win+R 直接输）

- `shell:startup` → 当前用户开机启动文件夹
- `shell:common startup` → 所有用户开机启动文件夹
- `shell:desktop` → 桌面
- `shell:my pictures` → 图片
- `shell:my music` → 音乐
- `shell:my videos` → 视频
- `shell:downloads` → 下载
- `shell:documents` → 文档
- `shell:favorites` → 浏览器收藏夹
- `shell:appdata` → 当前用户 AppData\Roaming
- `shell:local appdata` → 当前用户 AppData\Local
- `shell:programs` → 开始菜单程序文件夹
- `shell:sendto` → 右键 “发送到” 菜单
- `shell:start menu` → 开始菜单根目录
- `shell:templates` → 右键新建模板文件夹
- `shell:recent` → 最近打开的文件
- `shell:fonts` → 字体文件夹
- `shell:windows` → C:\Windows 目录
- `shell:system` → C:\Windows\System32
- `shell:program files` → 程序安装目录
- `shell:common desktop` → 所有用户共用桌面
- `shell:userprofile` → 用户主目录（C:\Users\ 用户名）

#### 实用系统命令（也是 Win+R 直接输）

- `msconfig` → 系统配置（启动项、服务）
- `services.msc` → 服务
- `regedit` → 注册表
- `gpedit.msc` → 组策略（专业版才有）
- `control` → 控制面板
- `inetcpl.cpl` → Internet 选项
- `ncpa.cpl` → 网络连接
- `devmgmt.msc` → 设备管理器
- `diskmgmt.msc` → 磁盘管理
- `taskmgr` → 任务管理器
- `mstsc` → 远程桌面
- `calc` → 计算器
- `notepad` → 记事本
- `cmd` → 命令行
- `powershell` → PowerShell

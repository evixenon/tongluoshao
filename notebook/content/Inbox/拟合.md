## 二项式拟合

用抛物线 $y = ax^2 + bx + c$ 拟合弯曲曲线

适合：加速度变化、距离轨迹、能量损耗、畸变校正。

![[attachments/Pasted image 20260324104352.png]]

OpenCV 直接求解，不用手写矩阵求逆：

```cpp
#include <opencv2/opencv.hpp>
// 输入离散点 vector<cv::Point2f> pts

cv::Mat X, Y;
// 1. 构造成A矩阵和y向量
for(auto& p : pts){
    X.push_back(cv::Matx1d( (double)p.x*p.x, p.x, 1.0 ));
    Y.push_back( (double)p.y );
}
// 2. 最小二乘求解
cv::Mat res;
cv::solve(X, Y, res, cv::DECOMP_SVD); 

double a = res.at<double>(0);
double b = res.at<double>(1);
double c = res.at<double>(2);
// 拟合式: y = a*x*x + b*x + c
```

典型工程用途
- 相机标定: 镜头径向畸变二次校正
- 轨迹预测: 球类抛物线飞行拟合
- 平滑滤波: 局部窗口二次去噪
- 物理建模: 自由落体 $s = \frac{1}{2}gt^2$

## 5.  解除程序重启验证

### 知识点
#### 字符串插件
比如搜 ascii 搜不出 VB 的字符串
智能包含 ascii 和 unicode

搜索结果页 `<c-f>` 搜索, `b` 下一个

#### 下断点
- `<c-g>` 直接断 api, 比如 CreateFileA
- `<c-n>` 查找函数参考/在每个调用设置断点
- 插件 `ApiBreak`/`API断点设置工具`

#### 重启验证
指程序启动时验证注册信息

- 基础: 注册信息输入 -> 程序重启 -> 执行验证机制 -> 正常执行程序
- 扩展: 注册信息输入 -> 执行部分验证/假验证 -> 程序重启 -> 执行真验证 -> 正常执行程序

重启验证的写入信息可能在文件或注册表

定位方法:
- 字符串定位
- procmon 等监控工具
- API 定位
#### Procmon
filter filter reset ok 过滤程序
工具栏的选项分别是监控注册表, 文件, 网络, 进程线程

#### 系统 API
- CreateFileA/W 创建文件
- ReadFile
- WriteFile
- CloseHandle

读取文件: CreateFile -> ReadFile -> CloseHandle
写入文件: CreateFile -> WriteFile -> CloseHandle

- RegCreatKey 创建注册表
- RegOpenKey 打开注册表
- RegQueryValueKey(Ex) 查询某个键值
- RegSetValueEx 写入注册表

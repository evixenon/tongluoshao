 点积 `a · b`

- 公式：`a · b = |a||b|cosθ`
- 几何意义：方向相似度 + 投影量
    - `a · b > 0`：夹角 < 90°，大体同向
    - `a · b = 0`：正交
    - `a · b < 0`：夹角 > 90°，大体反向
- 若先单位化（`|a|=|b|=1`），则 `a · b = cosθ`，直接表示夹角。
- 直观理解：`a` 在 `b` 方向上的“分量大小”（乘上 `|b|` 的版本）。

 叉积 `a × b`（3D）

- 公式：`|a × b| = |a||b|sinθ`
- 几何意义：垂直于两向量张成平面的法向量
    - 方向由右手定则决定（从 `a` 旋到 `b`）
    - 长度等于平行四边形面积，表示“非共线程度”
- 特殊情况：
    - `a × b = 0`：共线（或有零向量）
    - 长度越大：越接近垂直（在模长固定时）
